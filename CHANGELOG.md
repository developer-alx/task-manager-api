- PostgreSQL integrado

- CRUD de usuários

- Controle de acesso (RBAC)
- Swagger
- Docker Compose
- Migrations com node-pg-migrate
- Arquitetura em camadas

- Correção do script de produção (`start`)
- Remoção da pasta `dist` do versionamento
- Atualização do `.gitignore`
- Configuração do repositório GitHub
- Configuração SSH para autenticação com GitHub
